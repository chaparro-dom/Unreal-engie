Más Trailers de Juegos en Unreal Engine 5

Descubre una colección ampliada de trailers de los juegos más impresionantes desarrollados con Unreal Engine 5

Juegos de Acción y Aventura

Dragon Age: The Veilguard

La nueva entrega de la saga Dragon Age aprovecha Unreal Engine 5 para crear un mundo de fantasía con gráficos espectaculares y efectos visuales impresionantes.

Redfall

Este shooter cooperativo de Arkane Studios utiliza Unreal Engine 5 para crear un mundo abierto detallado con efectos de iluminación y sombras dinámicas.

Juegos de Terror y Supervivencia

The Callisto Protocol

Este juego de terror espacial utiliza Unreal Engine 5 para crear ambientes claustrofóbicos con una iluminación atmosférica y detalles gráficos impresionantes.

Silent Hill 2 Remake

El remake del clásico juego de terror utiliza Unreal Engine 5 para recrear la atmósfera opresiva de Silent Hill con gráficos modernos y efectos visuales mejorados.

Juegos de Rol y Mundo Abierto

Avowed

Este RPG de mundo abierto de Obsidian Entertainment utiliza Unreal Engine 5 para crear paisajes vastos y detallados con efectos de iluminación realistas.

Fable

El regreso de la icónica saga Fable utiliza Unreal Engine 5 para crear un mundo de fantasía vibrante con una gran atención al detalle y efectos visuales impresionantes.

Demostraciones Técnicas

Unreal Engine 5 - Valley of the Ancient

Esta demostración técnica muestra las capacidades de Nanite y Lumen en Unreal Engine 5, con un nivel de detalle y realismo sin precedentes.

Unreal Engine 5 - Lyra Demo

Lyra es un proyecto de ejemplo que muestra cómo crear un juego de disparos con Unreal Engine 5, utilizando todas sus características avanzadas.

Juegos de Plataformas

Crash Bandicoot 4: It's About Time

La nueva aventura de Crash utiliza Unreal Engine para crear mundos coloridos y detallados con animaciones fluidas y efectos visuales impresionantes.

Kena: Bridge of Spirits

Este juego de aventuras y plataformas utiliza Unreal Engine 5 para crear un mundo mágico con una estética inspirada en películas de animación y efectos de partículas avanzados.

Juegos de Construcción y Gestión

Planet Coaster 2

La secuela del popular simulador de parques de atracciones utiliza Unreal Engine 5 para crear parques detallados con efectos de iluminación realistas y simulaciones físicas avanzadas.

Manor Lords

Este juego de estrategia medieval y construcción de ciudades utiliza Unreal Engine 5 para crear asentamientos detallados con sistemas de clima dinámicos y efectos atmosféricos realistas.

Remakes y Remasterizaciones

Dead Space Remake

El remake del clásico juego de terror espacial utiliza Unreal Engine 5 para recrear la atmósfera claustrofóbica de la USG Ishimura con iluminación volumétrica y efectos de partículas avanzados.

System Shock Remake

El remake del clásico juego de rol y acción utiliza Unreal Engine 5 para recrear la estación espacial Citadel con gráficos modernos y efectos de iluminación neón impresionantes.

Juegos de Disparos y FPS

S.T.A.L.K.E.R. 2: Heart of Chornobyl

Esta secuela utiliza Unreal Engine 5 para recrear la Zona de Exclusión de Chernóbil con un nivel de detalle sin precedentes, aprovechando Nanite para los entornos y Lumen para la iluminación atmosférica.

Black Myth: Wukong

Este juego de acción basado en la mitología china aprovecha las capacidades de Unreal Engine 5 para crear efectos de partículas impresionantes y combates fluidos con una calidad visual extraordinaria.

Juegos de Estrategia

Age of Mythology: Retold

Este remake del clásico juego de estrategia utiliza Unreal Engine 5 para recrear las batallas mitológicas con un nivel de detalle impresionante y efectos visuales mejorados.

Homeworld 3

La nueva entrega de esta saga de estrategia espacial utiliza Unreal Engine 5 para crear batallas espaciales espectaculares con efectos de iluminación y partículas avanzados.

Simuladores

Test Drive Unlimited Solar Crown

Este simulador de conducción utiliza Unreal Engine 5 para recrear la isla de Hong Kong con un nivel de detalle fotorrealista, aprovechando Nanite para los entornos y Lumen para la iluminación dinámica.

Instinction

Este juego de supervivencia con dinosaurios utiliza Unreal Engine 5 para crear entornos naturales detallados y criaturas con comportamientos realistas gracias a los sistemas avanzados de IA.

Replaced

Little Devil Inside
